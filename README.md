# AAPL Hisse Fiyat Analiz ve Tahmin Projesi

Bu proje, Python ve İstatistiksel yöntemler kullanarak Apple (AAPL) hisse senetlerinin tarihsel verilerini analiz etmek ve doğrusal regresyon modeli ile gelecek fiyat eğilimlerini tahmin etmek amacıyla geliştirilmiştir.

## Proje Hakkında
- **Veri Kaynağı:** Yahoo Finance (`yfinance`)
- **Analiz Yöntemi:** Doğrusal Regresyon (Linear Regression)
- **Kütüphaneler:** Pandas, Scikit-Learn, Matplotlib

## Kullanılan İstatistiksel Metrikler
- **Doğrusal Regresyon:** Fiyat hareketlerinin genel trendini belirlemek için kullanılmıştır.
- **MAE (Mean Absolute Error):** Modelin başarısını ölçmek için kullanılan hata payı metriğidir. Şu anki model hata payı: **$12.83**
